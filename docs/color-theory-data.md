# Color-theory plot data

The Chart.js configurations in `public/assets/color-theory/` were generated by
a temporary Python script from CIE CSV files downloaded on 2026-10-10.
Before conversion, the script verified the SHA-256 checksums against the CIE
metadata, the column counts, wavelength spacing, and finite nonnegative powers.

- CIE 2019, **CIE standard illuminant D65**, DOI
  [10.25039/CIE.DS.hjfjmt59](https://cie.co.at/datatable/cie-standard-illuminant-d65).
- CIE 2018, **CIE standard illuminant A – 1 nm**, DOI
  [10.25039/CIE.DS.8jsxjrsn](https://cie.co.at/datatable/cie-standard-illuminant-1-nm).
- CIE 2018, **Relative spectral power distributions of illuminants representing
  typical LED lamps**, DOI
  [10.25039/CIE.DS.vgssnyfg](https://cie.co.at/datatable/relative-spectral-power-distributions-illuminants-representing-typical-led-lamps).
  The article uses the LED-B3 column, a phosphor-type LED reference.

Creator and publisher: International Commission on Illumination (CIE), Vienna, AT.

The figures crop the data to 380–780 nm and independently normalize each curve
to its maximum in that interval. They compare spectral shapes, not absolute
power. D65 represents daylight, illuminant A represents typical incandescent
lighting, and LED-B3 is a reference LED distribution; they are not measurements
of specific lamps or of the Sun. Lines connect the original samples without
smoothing.

The resulting configurations contain 401 D65 samples, 401 illuminant A samples,
and 81 LED-B3 samples. Each serialized coordinate was checked against its source
sample after normalization. LED-B3 was selected by its column name in the CIE
metadata. No interpolation, smoothing, or downsampling was applied.

Each file uses the native Chart.js configuration format, with `{x, y}` samples
under `data.datasets[0].data`. The x coordinates are wavelengths in nanometers;
the y coordinates are the original powers divided by the maximum within
380–780 nm. Plot labels and axis limits live in these configurations. Shared
rendering code contains no spectral data or article-specific settings.

The temporary conversion script, downloaded CSV copies and metadata, old SVGs,
and Matplotlib dependency are not needed to build or run the site and have been
removed from the repository. The source links above provide the original data
and metadata if another conversion is needed.
